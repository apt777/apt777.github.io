Operating rules

이 사이트를 쓰는 원칙

1. 기록은 짧고 자주

매번 완성된 글을 쓰기보다, 배운 점과 막힌 점을 짧게 남기는 구조로 갑니다.

2. 카테고리는 계속 추가 가능

개발, 영어, 중국어 외에도 독서, 운동, 프로젝트 회고 같은 공간을 쉽게 늘릴 수 있습니다.

3. 민감한 데이터는 분리

정적 HTML은 인증을 직접 처리하지 못하므로, 중요한 기록은 반드시 보호된 배포 환경 뒤에 둡니다.

Security

보안 메모

이 저장소는 정적 사이트라서 코드만으로 "나만 로그인해서 보는 홈페이지"를 완성할 수는 없습니다. 진짜 보안은 배포 앞단에서 인증을 강제해야 합니다.

  • 정적 파일은 그대로 두고, 배포는 인증 프록시나 사설 네트워크 뒤에 둡니다.
  • GitHub Pages 개인 사이트는 기본적으로 공개 성격이라, 개인 전용 홈페이지 용도에는 맞지 않습니다.
  • 실제 배포 전에는 `docs/private-deployment.md` 기준으로 방식을 정하면 됩니다.
